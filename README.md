# Software FJ – Sistema POO sin base de datos

Ejecución (Python 3.8+, sin dependencias externas):

    cd src
    python main.py

El archivo de eventos y errores se genera en `logs/software_fj.log`.
Módulos: excepciones, registro, entidad (abstracta), cliente, servicio (abstracta + 3 subclases), reserva, main.
